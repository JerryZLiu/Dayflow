# Agent skills (PraxStack)

Skills for Dayflow Cloud Agents install **globally** to `~/.agents/skills`, not into this directory.

| File | Purpose |
|------|---------|
| `super-pro-packs.json` | Manifest of all PraxStack packs and install modes |
| `~/.agents/.skill-lock.json` | Global lock file (auto-generated by skills CLI after install) |
| `~/.agents/.skills-and-personas.json` | Prax personal workflow layer stamp (commit SHA) |
| `~/.agents/personas/` | Raw persona packs from skills-and-personas (reference) |

## Sync on a fresh VM

```bash
bash scripts/install-praxstack-skills.sh --with-tools
bash scripts/verify-super-pro-skills.sh
```

See [docs/super-pro-stack.md](../docs/super-pro-stack.md) for architecture, slash commands, and desktop-only steps.
